# 题目库填充操作指南

适用范围：涉外法治人才培养平台  
适用人员：内容录入人员、题库管理员  
更新时间：2026-08-08

## 一、入口与权限

- 使用管理员账号登录网页端，进入“管理后台 -> 题库”。
- 所有题目的新增、修改、删除、上下线都通过管理后台完成。
- 不要直接操作 uniCloud 控制台、数据库集合或云函数。
- 题目保存后云端立即生效，不需要重新部署代码。

## 二、标准流程

1. 用管理员账号登录网页端。
2. 进入“管理后台 -> 题库”。
3. 点击“新建题目”。
4. 按本指南填写题型、题干、选项、答案、维度、难度等字段。
5. 状态先选择“审核中”。
6. 复核无误后，再编辑改为“已上线”。
7. 用普通账号进入测评页，确认新题能正常展示和计分。

## 三、字段填写规则

### 1. 题型

| 题型 | 使用场景 |
| --- | --- |
| 单选题 | 只有一个正确答案 |
| 多选题 | 有两个及以上正确答案 |
| 判断题 | 答案为“对”或“错” |
| 主观题 | 论述题、案例分析题、简答题 |

### 2. 题目内容

- 题干必须完整、自洽，不能只写“根据上述案例”却没有案例材料。
- 引用法律、法规、条约、判例时，应写明规范名称和必要背景。
- 题目表述要避免歧义，确保非专业人员也能理解。

### 3. 选项

- 只用于单选题和多选题。
- 每行一个选项，格式为：`A. 选项内容`。
- 建议最多到 `E`，不要超过 5 个选项。
- 选项字母连续，不能重复，不能漏项。
- 选项内容应相互独立，避免出现两个明显重复的选项。

正确示例：

```text
A. 合同订立地
B. 合同履行地
C. 当事人国籍国
D. 标的物所在地
```

### 4. 答案

| 题型 | 填写方式 | 示例 |
| --- | --- | --- |
| 单选题 | 填一个选项字母 | `C` |
| 多选题 | 用逗号分隔多个选项字母，顺序不影响得分 | `A,C,D` |
| 判断题 | 填“对”或“错”，不要填“正确/错误” | `对` |
| 主观题 | 填参考答案要点 | 可填写分点参考答案 |

注意：

- 多选题必须列全所有正确答案，漏选或错选都不得分。
- 判断题标准写法是“对”和“错”，不要混用其他写法。
- 修改题型时，必须同步检查选项和答案是否匹配。

### 5. 维度

当前只能用以下 4 个固定值，不要自创维度：

- `国际私法`
- `国际经济法`
- `国际公法`
- `涉外商事法`

当前成绩报告只统计这 4 个维度。填写其他维度会导致该题不会正确计入个人维度成绩。

### 6. 难度

| 值 | 说明 |
| --- | --- |
| 初级 | 基础概念、制度理解 |
| 中级 | 规则应用、常见实务 |
| 高级 | 案例综合分析、跨制度比较 |

### 7. 状态

| 状态 | 含义 |
| --- | --- |
| 审核中 | 管理后台可见，测评页不可见 |
| 已上线 | 测评页会读取该题 |

建议流程：新建时为“审核中”，复核通过后再“已上线”。

### 8. 主观题补充字段

- 案例材料：填写完整案例事实，可留空。
- 作答提示：填写答题角度、字数要求、参考思路，可留空。
- 答案：填写参考答案，主观题当前不参与自动评分，只保存作答内容。

## 四、上线规则

- 当前测评页会一次性加载全部“已上线”客观题和全部“已上线”主观题。
- 还没有抽题组卷功能，不要把整个题库一次性全部上线，否则测评会变得很长。
- 专项测评当前也复用同一批已上线题目，暂时不要按“专项”独立分类填题。
- 暂时不想展示的题改为“审核中”，不要删除。
- 只有确认彻底废弃的题才删除；删除前确认没有正在进行的测评依赖该题。
- 不要重复录入默认题。首次部署后如果题目集合为空，系统会自动写入一批默认题。

## 五、上线前验收清单

- [ ] 题干完整，没有悬空引用。
- [ ] 单选答案与正确选项一致。
- [ ] 多选答案列全，没有漏项。
- [ ] 判断题答案是“对”或“错”。
- [ ] 维度使用的是 4 个固定值之一。
- [ ] 难度已设置。
- [ ] 状态为“审核中”，复核后再改成“已上线”。
- [ ] 用普通账号进入测评，确认题目出现并能计分。
- [ ] 多选题故意选错一次，确认不得分。
- [ ] 把题目改回“审核中”，确认测评页不再展示。

## 六、常见错误

- 多选题漏填正确答案，导致用户无法得分。
- 判断题填写“正确/错误”，导致系统无法匹配标准答案。
- 选项格式不统一，例如没有写字母、多行合并成一个选项。
- 维度自创名称，导致题目不计入报告维度。
- 没有先保存“审核中”，直接上线未复核题目。
- 把大量题目同时上线，导致测评卷过长。
- 在 uniCloud 控制台直接改题，绕过管理后台的字段规则和权限校验。

## 七、当前限制

- 主观题编辑时，系统暂时把类型统一保存为普通论述题，案例分析题的类型标签会丢失；案例材料仍可正常录入和使用。
- 当前没有批量导入功能，只能逐题录入。后续如果提供 Excel/CSV 导入模板，再按模板批量导入。
- 当前测评没有抽题组卷，题目数量变化会直接影响测评长度。

## 八、操作红线

- 不使用管理后台以外的入口改题目。
- 不批量上线未复核题目。
- 不删除仍在使用的题。
- 不自创能力维度。
- 不改云函数代码、DB Schema 或集合结构。

如需批量导入模板或发现题目录入异常，请联系平台管理员，不要自行修改云端数据。
