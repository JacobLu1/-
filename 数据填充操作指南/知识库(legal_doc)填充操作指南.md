# 知识库数据填充操作指南

适用范围：涉外法治人才培养平台  
适用人员：内容录入人员、知识库管理员  
更新时间：2026-08-08

## 一、入口与权限

- 使用管理员账号登录网页端，进入“管理后台 -> 知识库管理”。
- 所有知识条目的录入、修改、上下线都通过管理后台完成。
- 不要直接操作 uniCloud 控制台、数据库集合或云函数。
- 知识条目保存后云端立即生效，不需要重新部署代码。

## 二、标准流程

1. 用管理员账号登录网页端。
2. 进入“管理后台 -> 知识库管理”。
3. 点击“新建知识条目”。
4. 填写标题、分类、文档类型、来源、日期、领域、地区、标签、摘要、正文等字段。
5. 保存后状态为“审核中”。
6. 复核无误后，再编辑为“已上线”。
7. 用普通账号进入法律库验证列表、搜索、筛选和详情。

## 三、字段填写规范

### 1. 标题

- 必填。
- 标题应准确反映法规、条约、案例或指南名称。
- 正式文件建议使用规范名称，例如：`《承认及执行外国仲裁裁决公约》（纽约公约）`。

### 2. 分类

当前只能使用以下固定分类，不要自创：

- 国际公法
- 国际私法
- 涉外民商法
- 国际贸易法
- 国际投资法
- 海商法
- 国际仲裁
- 综合

### 3. 文档类型

建议使用统一写法：

- 法律
- 行政法规
- 部门规章
- 司法解释
- 国际条约
- 案例
- 指南
- 其他

### 4. 来源

- 建议填写发布机构或出处。
- 例如：`全国人大常委会`、`最高人民法院`、`联合国国际贸易法委员会`。

### 5. 发布日期

- 格式统一为 `YYYY-MM-DD`。
- 没有明确日期时，可以填写资料整理日期。

### 6. 领域标签

- 使用逗号分隔。
- 例如：`国际贸易法,国际私法,数据保护法`。
- 领域用于法律库高级筛选。

### 7. 地区

- 使用逗号分隔。
- 例如：`中国,欧盟,国际`。
- 地区用于法律库高级筛选。

### 8. 关键词

- 使用逗号分隔。
- 例如：`CISG,国际贸易,合同法`。
- 关键词用于搜索和标签展示。

### 9. 摘要

- 建议必填。
- 用于法律库列表卡片展示。
- 摘要应概括条目主题和核心内容，不要写成宣传语。

### 10. 正文

- 填写完整内容，支持换行。
- 如果是案例，正文应包含案件事实、争议焦点、裁判/仲裁思路。
- 如果是法规，正文应包含条文或准确的解读内容。
- 不要只放标题或一句话。

### 11. 附件 / 原文 URL

- 选填。
- 可以填写完整 URL，例如：`https://xxx.bspapp.com/upload/file/doc.pdf`。
- 没有附件时留空。

### 12. 状态

| 状态 | 含义 |
| --- | --- |
| 审核中 | 管理后台可见，法律库不可见 |
| 已上线 | 法律库可读取 |

建议新建时为“审核中”，复核通过后再“已上线”。

## 四、上线规则

- 法律库只展示“已上线”条目。
- 列表、搜索、筛选、详情都会读取真实 `legal_doc` 数据。
- 暂时不想展示的条目改为“审核中”，不要删除。
- 只有确认废弃的条目才删除。
- 首次部署后系统会自动写入一批默认示例条目，内容人员应编辑或删除，不能把示例内容当作正式知识。

## 五、上线前验收清单

- [ ] 标题完整、规范。
- [ ] 分类使用固定分类之一。
- [ ] 文档类型、来源、日期已填写。
- [ ] 领域、地区、关键词填写正确。
- [ ] 摘要完整，能概括条目内容。
- [ ] 正文完整，不是占位文字。
- [ ] 状态为“审核中”，复核后再改为“已上线”。
- [ ] 普通账号法律库能看到条目。
- [ ] 搜索标题或关键词能命中。
- [ ] 分类、领域、地区、文档类型筛选正确。
- [ ] 点击详情能显示完整正文。
- [ ] 改回“审核中”后，法律库不再展示。

## 六、当前限制

- 当前没有批量导入功能，只能逐条录入。
- 知识库分类和筛选选项目前由管理后台固定配置。
- 专项测评知识条目分类尚未接入，暂时只按普通法律库展示。
- 正文当前支持文本和换行，暂不支持富文本编辑器。

## 七、操作红线

- 不直接操作 uniCloud 数据库。
- 不将示例条目当作正式知识上线。
- 不自创分类。
- 不批量上线未复核内容。
- 不删除仍在使用或引用中的条目。

如需批量导入模板或发现知识库异常，请联系平台管理员。
