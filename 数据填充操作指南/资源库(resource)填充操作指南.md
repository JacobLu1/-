# 资源库数据导入操作指南

适用范围：涉外法治人才培养平台  
适用人员：内容录入人员、资源管理员  
更新时间：2026-08-16

## 一句话流程

推荐新方法：在管理后台“录入学习资源”选择视频/音频/PDF/封面文件，系统自动上传到 uniCloud 云存储并填入 URL，保存并上线后到学习中心验证。

旧方法保留：手动上传 uniCloud 云存储 -> 复制文件 URL -> 管理后台粘贴 URL -> 保存并上线。

## 四类资源说明

资源集合统一使用 `type` 区分资源类型，管理后台新增和编辑时直接选择类型即可：

| type | 页面名称 | 主要字段 |
| --- | --- | --- |
| `video` | 视频资源 | `fileUrl` 视频地址、`cover` 封面、`meta` 时长 |
| `vocabulary` | 词汇 | `title` 英文词/短语、`description` 中文释义、`meta` 音标/难度、`content` 例句用法、`lang` 语言 |
| `reading` | 文本阅读 | `content` 阅读正文、`fileUrl` PDF/原文链接、`description` 简介 |
| `listening` | 听力训练 | `audioUrl` 音频地址、`content` 听力原文、`description` 中文/简介、`questions` 听力题目 |

所有类型都支持 `sortOrder` 排序号，数字越小越靠前。`legal_doc` 法律知识库仍由“知识库管理”维护，不要混入资源库。

词汇资源的 `lang` 语言分类固定为：英语、德语、法语、拉丁语、西班牙语。旧数据没有设置 `lang` 时，前端默认按“英语”展示。

## 推荐方法：管理端直传（新方法）

### 1. 视频资源

1. 使用管理员账号登录网页端。
2. 进入“管理后台 -> 资源管理”。
3. 在“录入学习资源”区域选择资源类型：视频资源。
4. 点击“选择视频文件”，选择本地视频文件，建议使用 `.mp4`，也可选择 `.mov`、`.m4v`、`.webm`。
5. 等待上传完成。系统会自动上传到 uniCloud 云存储的 `upload/video/` 目录，并自动填入“视频地址”。
6. 系统可读取时长时，会自动填入“时长”；资源标题为空时，会自动使用文件名作为标题。
7. 补充“视频分类”，例如 `国际仲裁`、`WTO法`、`跨境投资`、`海商法`。
8. 封面图可以点击“选择封面图”直接上传，也可以手动填写封面 URL；留空时页面会使用渐变占位。
9. 点击“保存并上线资源”，或先点“保存资源”再按旧方法里的上线步骤处理。

### 2. 文本阅读 PDF

1. 在“录入学习资源”区域选择资源类型：文本阅读。
2. 点击“选择 PDF 文件”，选择本地 `.pdf` 文件。
3. 等待上传完成。系统会自动上传到 `upload/file/` 目录，并自动填入“PDF / 原文链接”。
4. 填写“阅读正文”“阅读简介”“阅读主题”“难度/音标”等信息。
5. 点击“保存并上线资源”。

### 3. 听力训练音频

1. 在“录入学习资源”区域选择资源类型：听力训练。
2. 点击“选择音频文件”，选择本地音频，建议使用 `.mp3`，也可选择 `.m4a`、`.wav`、`.aac`。
3. 等待上传完成。系统会自动上传到 `upload/audio/` 目录，并自动填入“音频地址”。
4. 填写“听力原文”、中文/简介、“听力场景”，并维护听力题目。
5. 点击“保存并上线资源”。

### 4. 词汇资源

1. 在“录入学习资源”区域选择资源类型：词汇。
2. 填写“资源标题”为英文词或短语，例如 `abatement`。
3. 填写“中文释义”“音标/难度”“例句/用法”“词汇主题”。
4. 选择“语言分类”：英语、德语、法语、拉丁语、西班牙语。
5. 点击“保存并上线资源”。

注意：如果线上管理后台没有“语言分类”选项，或保存后语言字段丢失，说明 `resources` 云对象和 `resource.schema.json` 尚未部署，需要先联系平台管理员部署。

### 5. 封面图

视频、阅读、听力资源都可以点击“选择封面图”直接上传。系统会自动上传到 `upload/cover/` 目录并填入“封面 URL”；封面 URL 留空时，学习中心继续使用渐变占位。

### 6. 保存与上线

管理后台有两个保存按钮：

| 按钮 | 状态 | 效果 |
| --- | --- | --- |
| 保存资源 | 审核中 | 管理后台可见，学习中心不可见 |
| 保存并上线资源 | 已上线 | 学习中心可直接读取 |

建议新录入内容先“保存资源”复核，确认无误后再改为“已上线”。

## 旧方法：手动上传云存储后粘贴 URL（保留）

### 1. 准备文件

1. 准备一个视频/音频/PDF/封面文件，建议使用常用格式：
   - 视频：`.mp4`
   - 音频：`.mp3`、`.m4a`、`.wav`、`.aac`
   - 阅读文件：`.pdf`
   - 封面图：`.jpg`、`.jpeg`、`.png`、`.webp`
2. 文件名尽量使用英文字母、数字、下划线，例如 `test1.mp4`。
3. 不要使用中文、空格或特殊符号作为文件名，避免 URL 拼错。

注意：把视频放进项目里的 `backend/video/` 只是本地开发使用，不会自动变成线上视频，也不算已经上传。

### 2. 上传到 uniCloud 云存储

1. 打开 uniCloud 控制台 -> 云存储。
2. HBuilderX 中也可以在项目里点击“uniCloud -> 云存储”。
3. 确认选择的是当前项目正在使用的共享服务空间，不要新建空间。
4. 按文件类型进入对应目录；目录不存在时先新建：
   - 视频：`upload/video/`
   - 音频：`upload/audio/`
   - PDF：`upload/file/`
   - 封面图：`upload/cover/`
5. 点击上传，选择本地准备好的文件。
6. 等上传完成后，在文件列表中找到刚才上传的文件。

### 3. 复制文件 URL

1. 选中云存储里刚上传的文件。
2. 点击“详情”，复制其中的文件地址，即 URL。
3. 视频地址格式类似：

   `https://mp-a7547273-7e40-4a1b-ab50-2b0fb1a8a705.cdn.bspapp.com/upload/video/test1.mp4`

4. 先把地址粘贴到浏览器地址栏打开，确认能直接访问。
5. 确认地址以 `https://` 开头，并且是公开文件地址。

### 4. 在资源管理页导入

1. 使用管理员账号登录网页端。
2. 进入“管理后台 -> 资源管理”。
3. 在“录入学习资源”区域选择资源类型：视频资源、词汇、文本阅读或听力训练。
4. 填写资源标题。
5. 把复制好的 URL 粘贴到对应字段：
   - 视频：视频地址
   - 文本阅读：PDF / 原文链接
   - 听力训练：音频地址
   - 封面图：封面 URL
6. 词汇资源填写英文词/短语、中文释义、音标/难度、例句/用法、词汇主题和语言分类。
7. 根据需要填写视频分类、资源简介、日期、排序号等信息。
8. 点击“保存资源”。

### 5. 把资源设置为已上线

1. 在资源管理表格中找到刚新增的资源。
2. 点击“编辑”。
3. 检查资源地址、标题、简介、分类、语言、时长等信息。
4. 把审核状态改为“已上线”。
5. 点击“保存修改”。

状态说明：

| 状态 | 说明 |
| --- | --- |
| 审核中 | 管理后台可见，学习中心不可见 |
| 已上线 | 学习中心可读取 |

## 验证

1. 退出管理员账号。
2. 使用普通账号登录。
3. 进入“学习中心”，按资源类型验证：
   - 视频：进入视频学习并确认可以播放。
   - 词汇：进入“法律英语 -> 词汇积累”，选择对应语言，确认词条可见。
   - 文本阅读：进入文本阅读，确认正文和 PDF 可访问。
   - 听力训练：进入听力训练，确认音频、原文和题目正常。

## 常见错误

| 错误情况 | 原因 | 正确做法 |
| --- | --- | --- |
| 管理后台没有“选择视频/音频/PDF/封面”按钮 | 当前运行的前端版本较旧，或没有拉到最新代码 | 先更新网页端前端；仍无按钮时使用旧方法 |
| 选择文件后没有自动填入 URL | 直传上传失败，或当前环境未部署新版上传逻辑 | 检查网络后重试；仍失败时使用旧方法手动上传并粘贴 URL |
| 填了 `localhost` 或 `/backend/video/...` | 这是本地地址，线上用户无法访问 | 改填云存储 URL |
| 只填了文件名但还是打不开 | 文件没有上传到云存储对应目录 | 先上传文件，再填完整 URL |
| 填了 B站等外部视频地址 | 与项目自建学习资源定位不符 | 统一改用 uniCloud 云存储 MP4 |
| 资源状态是“审核中” | 学习中心只显示“已上线” | 编辑资源，改为“已上线” |
| `fileUrl` / `audioUrl` 为空 | 资源没有配置文件地址 | 补填真实可访问的云存储 URL |
| 地址带 `sign/expire` | 是临时下载链接，会过期 | 使用公开文件地址 |
| 视频是中文文件名 | URL 容易拼错 | 改用英文、数字、下划线文件名后重新上传 |
| 保存词汇后语言分类丢失 | `resources` 云对象或 `resource.schema.json` 未部署 | 部署后再录入，或联系平台管理员 |

## 关于外部视频

本项目以自建、可管理的云存储学习资源为主，不使用 B站等外部播放器地址。视频资源统一上传到 uniCloud 云存储并填写公开 MP4 URL。

## 操作红线

- 不直接操作 uniCloud 数据库。
- 不上线没有真实文件地址的资源。
- 不把 `localhost`、`/backend/video/...` 当成正式线上地址。
- 不批量上线未复核资源。
- 不删除正在使用的资源。
- 不把测试视频当作正式内容。
- 不静默新建或切换到另一个 uniCloud 服务空间。

如需批量导入模板或发现资源异常，请联系平台管理员。
