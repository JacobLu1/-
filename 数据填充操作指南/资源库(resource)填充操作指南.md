# 资源库数据填充操作指南

适用范围：涉外法治人才培养平台  
适用人员：内容录入人员、资源管理员  
更新时间：2026-08-08

## 一、入口与权限

- 使用管理员账号登录网页端，进入“管理后台 -> 资源管理”。
- 所有资源的录入、修改、上下线都通过管理后台完成。
- 不要直接操作 uniCloud 控制台、数据库集合或云函数。
- 资源保存后云端立即生效，不需要重新部署代码。

## 二、资源类型

| 类型 | 用途 | 展示位置 |
| --- | --- | --- |
| 视频资源 | 涉外法治视频课程 | 学习中心视频学习、视频详情页 |
| 法律英语资源 | 词汇、听力、术语、实务英语资料 | 学习中心法律英语资源、法律英语综合训练 |

当前管理端只启用 `video` 和 `english` 两种类型。文档资料上传功能尚未启用。

## 三、标准流程

1. 用管理员账号登录网页端。
2. 进入“管理后台 -> 资源管理”。
3. 选择资源类型：视频资源或法律英语资源。
4. 填写资源标题、资源地址、封面、简介等信息。
5. 保存后状态为“审核中”。
6. 复核无误后，再编辑为“已上线”。
7. 用普通账号进入学习中心验证展示效果。

## 四、字段填写规范

### 1. 资源类型

必须选择 `video` 或 `english`，不要混用。

### 2. 资源标题

- 必填。
- 标题要清晰、完整，例如：`国际商事仲裁实务精讲`。
- 不要使用无意义的编号作为标题。

### 3. 资源地址 / 文件名

- 可以填写完整 URL，例如：`https://xxx.bspapp.com/upload/video/video_01.mp4`。
- 也可以填写文件名，例如：`video_intl_arbitration_0.mp4`，系统会按视频基址自动拼接。
- 正式内容必须填写真实可访问的地址。
- 如果视频资源没有填写地址，网页端会暂时回退到默认示例视频，这不能作为正式上线状态。
- 法律英语资源没有地址时，学习中心会显示“暂无资源文件”。

### 4. 封面 URL

- 选填。
- 建议填写云存储中的封面图地址，方便学习中心展示。
- 不填时页面会使用默认渐变占位。

### 5. 资源简介

- 选填，但建议填写。
- 用于学习中心卡片展示和视频详情页课程简介。
- 简介应说明资源主题、适合人群和学习价值。

### 6. 时长 / 难度

- 视频资源填视频时长，例如：`45:30`。
- 法律英语资源填难度，例如：`初级`、`中级`、`高级`。

### 7. 日期

- 格式统一为 `YYYY-MM-DD`，例如：`2026-08-08`。

### 8. 状态

| 状态 | 含义 |
| --- | --- |
| 审核中 | 管理后台可见，学习中心不可见 |
| 已上线 | 学习中心可读取 |

建议新建时为“审核中”，复核通过后再“已上线”。

## 五、上线规则

- 只有“已上线”资源会出现在学习中心。
- 视频资源需要在视频详情页确认能正常播放。
- 法律英语资源需要确认文件地址可访问。
- 暂时不想展示的资源改为“审核中”，不要删除。
- 只有确认废弃的资源才删除。
- 首次部署后系统会自动写入一批默认示例资源，内容人员应编辑或删除，不能把示例资源当作正式内容。

## 六、上线前验收清单

- [ ] 资源类型正确。
- [ ] 标题完整、无错别字。
- [ ] `fileUrl` 已填写真实可访问地址。
- [ ] 封面、简介、时长或难度已补充。
- [ ] 状态为“审核中”，复核后再改为“已上线”。
- [ ] 普通账号学习中心能看到资源。
- [ ] 视频资源点击详情后能播放。
- [ ] 法律英语资源点击后能打开或复制资源地址。
- [ ] 改回“审核中”后，学习中心不再展示。

## 七、当前限制

- 文档资料上传功能尚未启用。
- 资源编辑目前是弹窗式修改，不支持一次编辑全部字段。
- 暂无批量导入模板，只能逐条录入。
- 资源分类默认可能是“待分类”，内容人员需要在编辑中补充准确分类。

## 八、操作红线

- 不直接操作 uniCloud 数据库。
- 不上线没有真实文件地址的正式资源。
- 不批量上线未复核资源。
- 不删除正在使用的资源。
- 不把默认示例资源当作正式内容。

如需批量导入模板或发现资源异常，请联系平台管理员。
