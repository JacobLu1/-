# 资源库数据导入操作指南

适用范围：涉外法治人才培养平台  
适用人员：内容录入人员、资源管理员  
更新时间：2026-08-14

## 一句话流程

准备好视频/音频/PDF 文件 -> 上传到 uniCloud 云存储 -> 复制文件 URL -> 管理后台按资源类型录入 -> 保存并上线 -> 到学习中心验证。

## 四类资源说明

资源集合统一使用 `type` 区分资源类型，管理后台新增和编辑时直接选择类型即可：

| type | 页面名称 | 主要字段 |
| --- | --- | --- |
| `video` | 视频资源 | `fileUrl` 视频地址、`cover` 封面、`meta` 时长 |
| `vocabulary` | 词汇 | `title` 英文单词、`description` 中文释义、`meta` 音标/难度、`content` 例句用法 |
| `reading` | 文本阅读 | `content` 阅读正文、`fileUrl` PDF/原文链接、`description` 简介 |
| `listening` | 听力训练 | `audioUrl` 音频地址、`content` 听力原文、`description` 中文/简介、`questions` 听力题目 |

所有类型都支持 `sortOrder` 排序号，数字越小越靠前。`legal_doc` 法律知识库仍由“知识库管理”维护，不要混入资源库。

## 第一步：准备视频文件

1. 准备一个视频文件，建议使用 `.mp4` 格式。
2. 文件名使用英文字母、数字、下划线，例如 `test1.mp4`。
3. 不要使用中文、空格或特殊符号作为文件名。

注意：把视频放进项目里的 `backend/video/` 只是本地开发使用，不会自动变成线上视频，也不算已经上传。

## 第二步：上传视频到 uniCloud 云存储

1. 打开 uniCloud 控制台 -> 云存储。
2. HBuilderX 中也可以在项目里点击“uniCloud -> 云存储”。
3. 确认选择的是当前项目正在使用的共享服务空间，不要新建空间。
4. 进入 `upload/video/` 目录；如果目录不存在，先新建 `upload/video/`。
5. 点击上传，选择本地准备好的视频文件。
6. 等上传完成后，在文件列表中找到刚才上传的视频。

## 第三步：复制视频 URL

1. 选中云存储里刚上传的视频文件。
2. 点击“详情”，复制其中的文件地址(即URL)。
3. 复制出来的地址格式类似：

   `https://mp-a7547273-7e40-4a1b-ab50-2b0fb1a8a705.cdn.bspapp.com/upload/video/test1.mp4`

4. 先把地址粘贴到浏览器地址栏打开，确认能直接播放。
5. 确认地址以 `https://` 开头，并且是 `.mp4` 这类媒体文件地址。

## 第四步：在资源管理页导入

1. 使用管理员账号登录网页端。
2. 进入“管理后台 -> 资源管理”。
3. 在“录入学习资源”区域选择资源类型：视频资源。
4. 填写资源标题，例如 `国际商事仲裁实务精讲`。
5. 把刚才复制的云存储视频 URL 粘贴到“资源地址 / 文件名”。
6. 根据需要填写：
   - 视频分类，例如 `国际仲裁`、`WTO法`、`跨境投资`、`海商法`
   - 封面 URL
   - 资源简介
   - 时长，例如 `45:30`
   - 日期，格式 `YYYY-MM-DD`
7. 点击“保存资源”。

保存后状态默认为“审核中”，学习中心暂时看不到。复核通过后需要继续执行下一步。

## 第五步：把资源设置为已上线

1. 在“视频资源管理”表格中找到刚新增的资源。
2. 点击“编辑”。
3. 检查资源地址、标题、简介、分类、时长等信息。
4. 把审核状态改为“已上线”。
5. 点击“保存修改”。

状态说明：

| 状态 | 说明 |
| --- | --- |
| 审核中 | 管理后台可见，学习中心不可见 |
| 已上线 | 学习中心可读取 |

### 视频封面如何显示

1. 把封面图上传到 uniCloud 云存储，建议放在 `upload/cover/` 目录。
2. 复制封面图 URL。
3. 在资源管理中编辑视频，把 URL 填入“封面 URL”。
4. 保存后，学习中心首页和全部视频页会自动显示真实封面。
5. 封面 URL 留空时，页面继续使用渐变占位，不会报错。

## 第六步：验证

1. 退出管理员账号。
2. 使用普通账号登录。
3. 进入“学习中心 -> 视频学习”。
4. 点击刚导入的视频。
5. 确认视频可以正常播放。

## 常见错误

| 错误情况 | 原因 | 正确做法 |
| --- | --- | --- |
| 填了 `localhost` 或 `/backend/video/...` | 这是本地地址，线上用户无法访问 | 改填云存储 URL |
| 只填了文件名但还是打不开 | 文件没有上传到云存储 `upload/video/` | 先上传文件，再填 URL |
| 填了 B站等外部视频地址 | 与项目自建学习资源定位不符 | 统一改用 uniCloud 云存储 MP4 |
| 资源状态是“审核中” | 学习中心只显示“已上线” | 编辑资源，改为“已上线” |
| `fileUrl` 为空 | 资源没有配置文件地址 | 补填真实可访问的视频 URL |
| 地址带 `sign/expire` | 是临时下载链接，会过期 | 使用公开文件地址 |
| 视频是中文文件名 | URL 容易拼错 | 改用英文、数字、下划线文件名后重新上传 |


## 关于外部视频

本项目以自建、可管理的云存储学习资源为主，不使用 B站等外部播放器地址。视频资源统一上传到 uniCloud 云存储并填写公开 MP4 URL。

## 本地开发验证（可选）

本地开发时也可以先在本地验证视频，但不能把它当成线上地址。

网页端本地验证：

1. 把视频放到：

   `D:\hbuilderxprojects\AI_DEMO\涉外法治人才培养\涉外法治人才培养（网页端）\backend\video\`

2. 资源地址临时填：

   `http://localhost:8080/backend/video/test1.mp4`

3. 上线前必须改成云存储 URL。

## 操作红线

- 不直接操作 uniCloud 数据库。
- 不上线没有真实文件地址的资源。
- 不把 `localhost`、`/backend/video/...` 当成正式线上地址。
- 不批量上线未复核资源。
- 不删除正在使用的资源。
- 不把测试视频当作正式内容。

如需批量导入模板或发现资源异常，请联系平台管理员。
