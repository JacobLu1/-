# 涉外法治人才培养平台

涉外法治人才培养平台包含**网页端**与**微信小程序端**两个应用，两端共用同一个 uniCloud（阿里云服务空间）后端，共享用户体系、学习资源与测评数据。

## 目录结构

```
涉外法治人才培养/
├── 涉外法治人才培养（网页端）/          # H5 网页端（管理后台 + 用户端）
│   ├── pages/                          # 页面
│   │   ├── login/ login.vue            # 登录页
│   │   ├── register/ register.vue      # 注册页
│   │   ├── admin/                      # 管理后台（数据总览/题库/用户/资源管理）
│   │   ├── survey/  result/  report/   # 测评相关
│   │   ├── legal-db/  ai-assistant/    # 法律库 / AI 助手
│   │   └── learning-center/            # 学习中心
│   ├── uniCloud-aliyun/                # 云服务端（云函数 + 数据库）
│   │   ├── cloudfunctions/
│   │   │   ├── users/                  # 用户体系云对象（登录/注册/用户管理）
│   │   │   ├── resources/              # 学习资源云对象
│   │   │   └── survey/                 # 测评结果云对象
│   │   └── database/                   # DB Schema（user/resource/survey_result）
│   └── pages.json                      # 页面路由
│
└── 涉外法治人才培养（微信小程序）/      # 微信小程序端
    ├── pages/                          # 页面（登录/注册/首页/测评/学习中心等）
    ├── static/                         # 静态资源
    └── scripts/serve-video.js          # 本地视频服务器（可选）
```

> **重要**：云函数和数据库只在「网页端」项目的 `uniCloud-aliyun` 目录维护与部署，小程序端只负责调用，不要再重复部署同名云函数，避免互相覆盖。

## 环境要求

| 工具 | 版本要求 | 用途 |
| --- | --- | --- |
| HBuilderX | 3.6.0+（需登录 uni-app 账号） | 打开/编译/部署项目 |
| 微信开发者工具 | 最新稳定版 | 运行小程序端 |
| uniCloud 服务空间 | 阿里云空间（可在 HBuilderX 中开通，有免费额度） | 后端运行环境 |

## 首次运行步骤

### 1. 导入项目

用 HBuilderX 分别打开两个项目文件夹：

- 菜单「文件 → 打开目录」选择 `涉外法治人才培养（网页端）`
- 菜单「文件 → 打开目录」选择 `涉外法治人才培养（微信小程序）`

打开时 HBuilderX 会自动识别为 uni-app 项目（目录下有 `manifest.json`）。

### 2. 开通并关联 uniCloud 服务空间

1. 确认 HBuilderX 右上角已登录 uni-app 账号
2. 在「网页端」项目中展开 `uniCloud` 目录 → 右键 → **关联云服务空间**（或「创建云服务空间」后关联）
3. 服务空间需选择 **阿里云**
4. 小程序端项目同样打开 `uniCloud` 目录 → 右键 → **关联云服务空间**，选择**同一个**服务空间（两端共用同一后端）
5. 若服务空间列表为空，先到 [uniCloud 控制台](https://unicloud.dcloud.net.cn) 开通一个免费的阿里云空间，再回来关联

### 3. 部署云函数与数据库（网页端项目操作）

在**网页端**项目中：

1. **上传 DB Schema**：右键 `uniCloud/database` 目录 → 「上传所有 DB Schema 及公共模块」。上传后会在云端自动创建 `user`、`resource`、`survey_result` 三个集合
2. **部署云函数**：分别右键 `uniCloud/cloudfunctions` 下的 `users`、`resources`、`survey` → 「上传部署」（选择云端依赖）

> 提示：部署时如果提示选择依赖，选「云端安装依赖」即可。部署成功后在控制台可以看到对应云函数（云对象）。

### 4. 运行网页端

1. 在「网页端」项目打开任意页面，菜单「运行 → 运行到浏览器 → Chrome」
2. 首次部署完成后，users 云对象会自动创建默认账号（见下文）
3. 打开登录页即可登录

### 5. 运行小程序端

1. 打开 `manifest.json` → 微信小程序配置 → 填入你自己的 **AppID**（没有可点「测试号」）
2. 菜单「运行 → 运行到小程序模拟器 → 微信开发者工具」（首次需在 HBuilderX 设置中配置微信开发者工具安装路径）
3. 微信开发者工具需开启「服务端口」（设置 → 安全设置 → 服务端口）并允许 HBuilderX 调用

## 默认账号

首次部署并调用云函数后，云端会自动写入两个默认账号：

| 账号 | 密码 | 角色 | 说明 |
| --- | --- | --- | --- |
| `admin001` | `123456` | 管理员 | 登录后进入管理后台 |
| `user001` | `123456` | 普通用户 | 登录后进入测评端 |

新用户也可在登录页点击「立即注册」自助注册。

## 常见问题

### 1. 登录提示「网络异常」或控制台报 `Method name is required`

- 确认 HBuilderX 已登录 uni-app 账号，且已正确关联阿里云服务空间
- 确认 `users` 云函数已部署到当前服务空间（步骤 3）
- 两端调用云对象统一使用 `uniCloud.importObject('users')`，不要使用 `uniCloud.callFunction`（云对象不支持该调用方式，会报 `Method name is required`）

### 2. 提示「账号不存在或密码错误」

- 确认已执行过步骤 3 的部署，且云函数被调用过一次（`_before` 会自动创建默认账号）
- 可在 uniCloud 控制台 → 云数据库 → `user` 集合查看是否有数据；为空则用注册页注册一个账号

### 3. 提示「云函数不存在 / FUNCTION_NOT_FOUND」

- 云函数没有部署到当前关联的服务空间，重新执行步骤 3 的部署

### 4. 网页端 H5 提示跨域（CORS）错误

- 在 uniCloud 控制台 → 云函数 → 对应函数 → 配置中确认 H5 域名已加入安全域名（本地调试通常不受影响）

### 5. 视频资源无法播放 / 如何上线视频

视频地址由两端 `utils/video-config.js` 统一提供：

- **本地开发**（默认，无需配置）：网页端走相对路径 `/backend/video/`；小程序端走本地视频服务器：
  ```
  cd 涉外法治人才培养（微信小程序）
  node scripts/serve-video.js
  ```
  启动后访问 `http://localhost:8972` 验证。

  > **小程序播放视频报 `ERR_CONNECTION_REFUSED` 或 `MEDIA_ELEMENT_ERROR: Format error`**：说明本地视频服务器未启动，先在「微信小程序」目录下执行上面的 `node scripts/serve-video.js`，再在微信开发者工具里重新编译。若改过端口，同步修改 `scripts/serve-video.js`（默认 8972）与 `utils/video-config.js` 中的 `VIDEO_BASE_LOCAL`。
  >
  > **真机预览**：视频服务器需监听局域网地址，把 `utils/video-config.js` 的 `VIDEO_BASE_LOCAL` 换成 `http://<电脑局域网IP>:8972/video/`（启动服务器时控制台会打印局域网地址），并保证手机与电脑在同一网络。
- **上线发布**：把 `backend/video/` 下的视频上传到 uniCloud 云存储（uniCloud 控制台 → 云存储），再把云存储目录地址填入 `utils/video-config.js` 中的 `VIDEO_BASE_ONLINE`（如 `https://xxx.bspapp.com/upload/video/`），重新打包两端即可。留空则自动用本地地址，不影响开发。

## 后端交接

### 1. 服务空间权限交接

uniCloud 服务空间**所有权无法转让**（云厂商强制绑定创建者账号），但可通过**协作者**机制授权对方完整管理：

1. 用创建者账号登录 [uniCloud Web 控制台](https://unicloud.dcloud.net.cn)
2. 选择目标服务空间 → 左侧菜单「成员管理」
3. 输入对方 **DCloud 账号邮箱**（HBuilderX 注册邮箱）→ 搜索 → 添加成员
4. 角色选择「管理员」（云函数、云数据库、内置存储等模块均有管理权限），对方即可部署云函数、上传 DB Schema、管理线上数据
5. 对方在 HBuilderX 登录自己的账号 → 右键 `uniCloud-aliyun` → 关联该服务空间，即可正常部署

注意：

- 协作者账号需先完成**实名认证**
- **只有空间创建者可以管理成员列表**，协作者不能增删成员
- 空间续费、删除等仍归创建者账号；协作者管理员可充值并开具发票
- 若需彻底脱离创建者账号，只能由新账号新建服务空间，再用数据库搬家工具迁移数据、重新上传云函数，并重新关联新空间 ID（会短暂影响线上服务）

## 注意事项

- 云函数、数据库 Schema 改动只在「网页端」维护，改完记得重新「上传部署」
- 两端共用同一套 `user` 集合：网页端用账号登录，小程序端用手机号登录（手机号需在注册/管理端维护）
- 小程序端首次运行时建议先在微信开发者工具里把「不校验合法域名」打开，方便本地调试
